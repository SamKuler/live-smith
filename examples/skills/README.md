# Arrangement Skill Examples

These are optional, user-imported examples for Live Smith's local Skill system.
They are not bundled into a user's installed catalog and are never enabled
automatically.

Import a `SKILL.md` from the Inspector's **Skills** tab, then enable or disable
it for the current Session:

- `arranging-section-energy` — section order, setup/payoff, and energy arcs at
  observed musical boundaries;
- `organizing-instrument-roles` — simultaneous foreground, anchor, support,
  motion, register, and density decisions;
- `developing-musical-variation` — controlled motif development with explicit
  invariants and return points.

The three Skills are intentionally orthogonal: when changes happen, which parts
occupy the moment, and how repeated material changes. They can be enabled
individually or together. None adds tools, actions, provider access, or Live
permissions.
